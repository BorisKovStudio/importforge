    What these results do — and do not — prove

    Recursive improvementAn execution fails, actual feedback is retained, and a later proposal changes the harness. An accepted proposal must pass the independent gate; a retry alone is not improvement.

    Self-editing harnessThe model edits bounded mappings, JOIN/VALIDATE procedures, tool access or context policies. It does not rewrite application code, invent new runtime tools or train model weights.

    Durable memorySaved procedures can be loaded by later runs. The restart example restores the same task at a safe checkpoint. It does not prove hours of autonomy, billions of tokens or recovery during an ambiguous external request.
